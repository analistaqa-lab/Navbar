# Contrato de data-testid sugerido

Para estabilizar a automação, padronize no componente real:

## Navbar
- `navbar`
- `navbar-logo-link`
- `navbar-drawer-toggle`
- `navbar-drawer`
- `navbar-cta-login`
- `uf-field`

## Dropdowns
- `navbar-dropdown-toggle-solucoes`
- `navbar-dropdown-panel-solucoes`
- `navbar-dropdown-toggle-paises`
- `navbar-dropdown-panel-paises`

## Breadcrumb
- `breadcrumb`
- `breadcrumb-current`

## Observação
Para outros dropdowns, use o padrão:
- `navbar-dropdown-toggle-{slug}`
- `navbar-dropdown-panel-{slug}`
